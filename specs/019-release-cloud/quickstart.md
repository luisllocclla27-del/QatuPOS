# Quickstart019

Desde la raíz del piloto: `pnpm release:check`, `pnpm release:test`, `pnpm typecheck`, `pnpm build:cloud`. Ninguno instala Supabase. Para instalación y consultas seguir [guía de entrega](../../docs/RELEASE-CLOUD.md). `pnpm cloud:secure check --config RUTA_ABSOLUTA_EXTERNA` valida configuración sin conectar; acciones install/migrate son explícitas y requieren proyecto identificado.
